# niku-no-noda
肉の野田 公式ホームページ

## 現在の状態(2026-11-01 時点)

| 場所 | 内容 |
|---|---|
| `index.html` + `images/` | 既存の公開サイト(**変更していません**) |
| `v2/` | 新しい試作版。製造風景の写真8点と、ベーコン・サルシッチャ・ローストビーフの紹介文を追加(公開中: https://naokiyoko1234-art.github.io/niku-no-noda/v2/) |
| `preview/niku-no-noda-v2.html` | v2を**1ファイルにまとめた確認用**。写真が中に入っているので、ダウンロードして開くだけで見られます |
| `materials/` | 素材台帳(`ledger.csv`、`LEDGER.md`)、写真の元データ(`incoming/`)、軽量化スクリプト |

## 公開前に必ず本人が確認すること
- 掲載写真が、実際に肉の野田で撮ったものであること(ネット・SNSから拾った画像は使用禁止)
- ローストビーフの説明(焼き色・火入れ・「和牛」表記)と、ご予約の案内
- ベーコンの熟成期間(14日)、豊後極み豚の名称
- 「無添加」などの表示は、根拠を確認してから(現在ページには書いていません)

## まだ入っていないもの
- ソーセージの腸詰めの写真・動画、製造風景の動画(1本25MBまで。長い動画は10〜20秒に切ってから)

## v2を公開するとき
本人の確認後に、`v2/` の中身を公開側へ反映します(既存サイトは、その時点まで変更しません)。
